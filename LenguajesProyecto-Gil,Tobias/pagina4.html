Código fuente

El código fuente es el conjunto de instrucciones que escribe un programador utilizando un determinado lenguaje de programación. En él se encuentra toda la información necesaria para indicar qué debe hacer un programa y cómo debe comportarse. El código fuente puede modificarse y mejorarse durante el desarrollo de un proyecto. Dependiendo del lenguaje utilizado, posteriormente puede ser compilado o interpretado para que las instrucciones puedan ser ejecutadas por una computadora.

Compiladores

Los compiladores son programas encargados de traducir el código escrito por un programador a otro formato que pueda ser ejecutado por la computadora. Durante este proceso también pueden detectar errores en el código y señalar dónde se encuentran. Algunos lenguajes utilizan principalmente este método para generar programas ejecutables antes de ponerlos en funcionamiento. C y C++ son ejemplos de lenguajes que habitualmente se compilan para producir código que pueda ejecutar el sistema.

Intérpretes

Los intérpretes son programas que se encargan de procesar y ejecutar instrucciones de un lenguaje durante la ejecución. En lugar de producir necesariamente un programa ejecutable completo antes de comenzar, el intérprete trabaja con el código para poder ejecutarlo. Este método puede facilitar las pruebas y el desarrollo de programas. Python es un ejemplo de lenguaje que suele ejecutarse mediante un intérprete, aunque los sistemas modernos pueden utilizar también otras técnicas para mejorar su rendimiento.
